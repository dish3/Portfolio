# NOVA: AI-Managed Personal Portfolio

NOVA is an AI-powered personal portfolio operating system. It brings together a Next.js web app, a FastAPI backend, platform connectors, and AI agents that prepare portfolio updates for human approval.

The application source, setup instructions, architecture details, and development commands are in the [`Portfolio` directory](Portfolio/).
